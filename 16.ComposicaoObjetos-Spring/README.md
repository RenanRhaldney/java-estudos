# 15 - Composição de Objetos

Projeto desenvolvido como parte dos estudos de Java, com foco em **Programação Orientada a Objetos (POO)** e no conceito de **composição de objetos**.

Este exercício consiste em cadastrar um trabalhador, seus contratos de trabalho e calcular a renda mensal com base nos contratos realizados em determinado mês.

## 📚 Conceitos praticados

- Programação Orientada a Objetos (POO)
- Composição de objetos
- Encapsulamento
- Enumeração (`enum`)
- Listas (`List`)
- `LocalDate`
- `Scanner`
- Métodos e construtores
- Relacionamento entre classes
- Iteração sobre coleções
- Organização de pacotes

## 🏗️ Estrutura do projeto

```text
src/
├── application/
│   └── WorkerProgram.java
│
├── entities/
│   ├── Department.java
│   ├── HourContract.java
│   └── Worker.java
│
└── entities.enums/
    └── WorkerLevel.java
```
